## Root Cause Analysis

The 401 errors are happening because:
1. Edge functions like `save-fx-rate` require valid JWT authentication
2. Functions verify the JWT token and check user role (admin/super_admin)
3. If no valid token is passed, they return 401 Unauthorized

The code in AdminDashboard.tsx and SuperAdminProfile.tsx tries to get the session manually but may have timing issues.
