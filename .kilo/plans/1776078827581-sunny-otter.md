# Plan: Vesicash Payout Integration & Dashboard UI

## Problem
1. The payout function uses outdated Vesicash API format
2. Need manual payout processing UI in super_admin dashboard

## Vesicash API Analysis

### Correct Payout Endpoint
- **URL**: `POST https://api.mor.vesicash.com/v1/payment/payout/process`
- **Headers**: 
  - `V-PRIVATE-KEY`: your private key
  - `V-PUBLIC-KEY`: your public key

### Mobile Money Payout Payload
```json
{
  "amount": 123,
  "countryId": "zambia_country_id",
  "transfer_to": "mobile_number",
  "momo_phone_number": "260999993000"
}
```

### Bank Transfer Payout Payload
```json
{
  "amount": 123,
  "countryId": "zambia_country_id",
  "transfer_to": "bank",
  "bank_id": "zmb_zanaco_001",
  "account_number": "1234567890"
}
```

### Get Banks List
- **URL**: `GET https://api.mor.vesicash.com/v2/banks`
- **Body**: `{"country_code": "zm"}`
