## Issue 2: 401 Unauthorized Errors

Multiple API calls returning 401:
- `get-user-settings`
- `in-dashboard-data`  
- `eq.currency`

These are likely caused by RLS (Row Level Security) policies or expired auth tokens. The app needs valid Supabase auth to access these functions. Once the Settings error is fixed, verify if these errors persist by:
1. Logging out and logging back in
2. Checking Supabase dashboard RLS policies for the tables/functions

## Issue 3: 503 get-fx-rate

503 indicates the edge function may be down or has configuration issues. Check the function in Supabase dashboard.
